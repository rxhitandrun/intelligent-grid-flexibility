# Intelligent Grid Flexibility

## Research Objective

Investigate how distributed energy resources can be
coordinated to provide electricity network flexibility
while respecting network constraints and consumer
energy requirements.

## Methodology

- AC distribution network modelling using pandapower
- Distributed energy resource modelling
- Time-series power flow
- Network-constrained flexibility optimisation
- Sensitivity analysis and validation

## Research Status

Under development.

Initial experiments will use synthetic network
parameters and operating conditions.

## Environment

Python 3.14.7
pandapower 3.5.6
Visual Studio Code
